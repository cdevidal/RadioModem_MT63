Справка / FAQ

Быстрый старт

  1. Откройте приложение и нажмите Start для запуска модема.
  2. Подключите клиент по KISS/TCP к 127.0.0.1:8100 (или вашему адресу/порту).
  3. Следите за уровнями RX/TX, SNR/BER. Избегайте клиппинга RX.

Профили

Используйте Settings → Профиль, чтобы выбрать пресет. Профиль устанавливает FFT, CP, Carriers, Pilots, PLL, Soft-FEC, Interleave и задержки TX. Значения можно корректировать вручную (статус станет Изменён).

Параметры MT63

  • Размер FFT: больше → выше устойчивость, но больше CPU/задержка.
  • Циклический префикс (CP): защита от межсимвольных искажений; больше → больше задержка.
  • Поднесущие: число активных поднесущих.
  • Пилоты / PLL: синхронизация и слежение по фазе/частоте.
  • Soft-FEC: мягкое декодирование Хадамара-64 снижает BER в шуме.
  • Interleave: Legacy / Short (по столбцам) / Long (диагональное разнесение).

Sideband/Reticulum (KISS/TCP)

Адрес и порт задаются в настройках; убедитесь, что клиент подключается туда же.

Качество сигнала

Избегайте клиппинга RX; ориентируйтесь на стабильный средний уровень. В разделе Statistics смотрите графики SNR/BER.

Диагностика

В Log можно экспортировать события; повышенные уровни логирования включайте только при необходимости.

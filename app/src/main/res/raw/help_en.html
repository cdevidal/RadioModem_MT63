Help / FAQ

Quick Start

  1. Open the app, press Start to run the modem service.
  2. Connect your client via KISS/TCP to 127.0.0.1:8100 (or your bind/port).
  3. Watch RX/TX levels, SNR/BER. Avoid clipping on RX.

Profiles

Use Settings → Profile to pick a preset. Each profile sets FFT, CP, Carriers, Pilots, PLL, Soft-FEC, Interleave and TX delay/tail. You may tweak parameters afterwards (status becomes Modified).

MT63 Parameters

  • FFT size: larger → more robustness, higher CPU/latency.
  • Cyclic Prefix (CP): guards against ISI; larger → more delay.
  • Carriers: active subcarriers count.
  • Pilots / PLL: synchronization and phase/frequency tracking.
  • Soft-FEC: soft Hadamard-64 improves BER in noise.
  • Interleave: Legacy / Short (column-major) / Long (diagonal spread).

Sideband/Reticulum (KISS/TCP)

Bind address/port in Settings; ensure client points to the same pair.

Signal Quality

Avoid RX clipping; aim for steady mid-level. Use Statistics screen to see SNR/BER trends.

Diagnostics

Use Log to export events; enable higher levels only when needed.
